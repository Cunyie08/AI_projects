# Applied AI Projects

## Overview
This repository contains applied artificial intelligence projects developed as part of my MSc Data Science program and AI Engineering Fellowship. The projects focus on building practical AI systems, ranging from classical deep learning models to modern LLM-powered applications.

The work here emphasizes **real-world applicability**, clean system design, and iterative learning.

---

## Projects Included

### 🔎 Retrieval-Augmented Generation (RAG) System
- Designed an AI assistant that retrieves relevant documents and generates context-aware responses.
- Implemented embedding-based retrieval and response generation pipelines.
- Focused on improving factual grounding and response relevance.

**Key concepts:** RAG pipelines, embeddings, vector search, prompt engineering

---

### 🧠 Perceptron (Deep Learning)
- Implemented a perceptron-based neural network to explore foundational deep learning concepts.
- Studied decision boundaries, activation functions, and model behavior.
- Built as a learning-oriented project to strengthen intuition around neural networks.

**Key concepts:** Neural networks, supervised learning, model training

---

### 📄 AI-Powered CV Chatbot
- Developing an LLM-powered chatbot that generates and refines CV content based on user input.
- Focused on prompt structuring, personalization, and conversational flow.
- Explored responsible use of generative AI for professional applications.

**Key concepts:** LLMs, prompt engineering, conversational AI
